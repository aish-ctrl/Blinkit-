Blinkit Sales & Business Performance Dashboard

An interactive Power BI dashboard designed to analyze Blinkit's retail sales performance, product categories, outlet characteristics, and customer ratings. The project transforms retail data into actionable business insights through data cleaning, data modeling, DAX calculations, and interactive visualizations.

Project Overview

This project explores retail sales data inspired by Blinkit, a quick-commerce platform, to understand sales distribution, product performance, and outlet-level trends. The dashboard provides a consolidated view of key performance indicators (KPIs), enabling users to compare sales across product categories, outlet sizes, outlet locations, and outlet types.

Project Objectives

- Analyze overall retail sales and order-related performance.
- Identify top-performing product categories.
- Compare sales across outlet sizes, locations, and types.
- Examine sales trends based on outlet establishment year.
- Present business metrics through an interactive dashboard.

Tools & Technologies

- Power BI Desktop — Dashboard development and data visualization
- Power Query Editor — Data cleaning and transformation
- DAX — Measures and KPI calculations
- Power BI Data Modeling — Relationships between datasets
- Excel, CSV, and Web Data — Data sources used in the project

Dashboard Features

- KPI Cards:Total sales, average sales, number of items, and average rating.
- Interactive Filters: Filter the report by outlet location, outlet size, and item type.
- Product Analysis: Compare sales performance across product categories.
- Outlet Analysis: Evaluate performance by outlet size, location tier, and outlet type.
- Sales Trend Analysis: Explore outlet establishment trends across years.
- Comparative Visualizations: Use charts, tables, and slicers to examine business performance from multiple perspectives.

Key Business Insights

1. Overall Sales:** The dashboard reports approximately $1.20 million in total sales, with average sales of $141 and an average rating of 3.9.
2. Outlet Performance: Supermarket Type 1 is the leading outlet type in the displayed report, contributing approximately $788K in sales.
3. Outlet Location: Tier 3 outlets contribute approximately $472.13K, followed by Tier 2 at $393.15K and Tier 1 at $336.40K.


These insights reflect the values visible in the dashboard and should be interpreted within the scope of the dataset.*

How to Use

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` report file in Power BI Desktop.
4. Explore the dashboard using the available filters and interactive visualizations.
5. If you want to refresh the data, configure the required data-source paths and credentials.
